Trust who it is.

Don't trust where the agent is. HOLA verifies on-chain — no certificate authority and no trusted broker in the trust chain. Trust the signature, not the transport: the same proof works on whatever channel the conversation already uses — email, chat, a video call, or an API. Anyone can check it, so it holds up in corporate interactions.

The credential is an IdentyClaw Passport; the proof is a HOLA line.

Executive mutual authentication

Executives corresponding across firms, with no shared platform, each prove they currently control the credential the other expects. The proof rides the channel they already share — email, chat, the video call, or an API. Security and compliance can check it themselves. That is the ad-hoc, cross-company case where device attestation and video liveness alone are not enough: they need a trusted device or platform on both ends, and they do not produce a verifier-independent proof.

Live agent proof

When a video agent runs an interview or a customer conversation, the same multi-channel proof says this stream is the authentic agent, not a clone. The Passport’s facial ID is the face people recognize on that stream — a 12-letter code that encodes a readable persona, so the face you see matches the credential you check. Anyone can verify it, including people who never registered that agent. Give it a test drive.

At larger scale

Many-to-many agent collaboration

At scale, 1,000 × 1,000 agents collaborating requires 1 million directional pairwise API keys — or only 2,000 Passports, one per agent. Webhooks face the same pairwise trap: 1 million directional peer-pair HMAC shared secrets — or the same Passport, because the proofs are signed at the origin. Identity scales linearly, not geometrically.
